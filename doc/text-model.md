# `.scn` 文本模型

剧情不是 KAG 的 `.ks`，而是编译进 **PSB** 的结构化对象（外壳见 [file-formats.md](file-formats.md) §2）。
本文说明：哪些字段是要翻译的文本、哪些是内部键、替换文本时必须同步维护什么。

数据规模（本作实测，用于判断口径是否成立）：

| 项 | 民汉补丁（绿茶 SANA EDITION 汉化） | Steam 版（简中域，`data.xp3`+`patch.xp3`） |
|---|---|---|
| 脚本 | 118 | 102 |
| 场景（`label`） | 134 | 117 |
| 对白行 | 28,254 | 23,245 |
| 选项 | 11 | 11 |
| 对白总字数 | 514,477 | 386,428 |
| 逐页说话人（`alt_speaker`）非空页数 | 242 | 15,297 |
| 民汉日文残留（共有脚本内） | 10 行 | — |

## 1. 场景（`root["scenes"][i]`）

| 键 | 含义 | 可翻译 |
|---|---|---|
| `label` | 场景标签（`*start`、`*normal`、`*replay_xx`、`*dummy1`…） | ❌ 跳转目标 |
| `firstLine` | 该场景第一行的全局行号 | ❌ |
| `lines` | 命令流（`envupdate`/`update`/`wait`/`bg`/`anm_*`…），含资源名与内部键 | ❌ |
| `texts` | 对白行数组 | ✅ 见 §2 |
| `selects` | 选项数组（有分支的场景） | ✅ 见 §4 |
| `nexts` / `preevals` / `postevals` | 跳转与标志位（`f.ag_route_1 = 0`、`sf.clear_sn = 1` 之类的 TJS 片段） | ❌ |
| `title` / `spCount` / `version` / `selectInfo` | 元数据（本作 `title` 全为空串） | ❌ |

## 2. 对白行（`scene["texts"][i]`，固定 5 元）

```
[0] speaker     说话人显示名（string|null）                    ✅ 可翻译
[1] pages[]     分页数组                                       见下
[2] attrs[]     每页属性 dict：name=语音角色键, pan, type, voice=语音文件名   ❌
[3] flag        本作恒为 64（不动）
[4] {data, env, …}  命令容器（转场 / 立绘 / BGM 等）              ❌
```

分页两种形态：

```
3 元：[voice_gate|null, text, length]
5 元：[voice_gate|null, text, length, text_plain, text_plain]
```

| 字段 | 含义 | 处理 |
|---|---|---|
| `[0]` | **逐页**说话人覆盖（`？？？`、`全体女生`…），非空时覆盖行首 speaker | ✅ 可翻译 |
| `[1]` | 正文；换行是字面两个字符 `\` `n`；行内标记见 §5 | ✅ 翻译目标 |
| `[2]` | `length`，口径见 §3 | ⚠️ 替换后必须重算 |
| `[3]` | `text_plain`：去掉 `\n` 的同一段（`[3]`/`[4]` 正常共用一个字符串槽） | 见 §6 |

实测分布：3 元分页 48,823 页 / 5 元分页 20,721 页（同一份数据里两种并存，**没有 `text_plain` 不代表缺失**）。

## 3. `length` 字段的三种口径

| 数据来源 | 口径 | 判据 |
|---|---|---|
| 某民间汉化（基于日文原版） | **原始长度**：行内标记与 `\n` 全算 | 69,539/69,544 页满足 `length == UTF-16 码元数` |
| Steam 官方（简中 / 繁中域） | **显示长度**：删掉 `%NNN;`、`#RRGGBBAA;`、`#;`、`\k`、`\p` 后再算，`\n` 仍算 2 | 含标记的 84（简中）/ 85（繁中）页全部符合；其余两派等价 |
| Steam 官方（英文域） | **显示长度且字面 `\n` 计 0**：`%NNN;`、`#RRGGBBAA;`、`#;`、`\k` 全部不算，`\n` 也不算 | 138 页不符合「UTF-16 码元数」，差值逐条等于被删标记的字符数（含 `\n` 的 2） |

例：`%205;磅──！！！` → 官方记 `6`，同一句在汉化侧会记 `11`；英文域 `“Hmmm, okay.”\n“Okay, then...”`（30 码元）→ 记 `28`。

规则：**回写哪一版就按哪一版的口径算，同一批产物不得混用**。本仓库统一封装为`tool/scn.py::page_length()`（显示长度；`\n` 仍按两字符计 —— 对简中 / 繁中域正确，**英文域会多算 `\n` 的 2**，但本项目的回写目标只有中文域，不影响）。字段只影响自动/快进节奏，写错不崩。

## 4. 选项（`scene["selects"][i]`）

```
{ render:1, selidx:0, storage:"…", target:"*start", text:"是" }
```

- `text` 是选项文本 → ✅ 可翻译。
- `button: "yes"|"no"` 形态没有 `text`，按钮文字来自 UI 层（`.tjs`），不在脚本里。

## 5. 行内标记（必须原样保留）

| 形式 | 例子 | 作用 |
|---|---|---|
| `%NNN;` | `%205;嘭！！！`、`%164;“出去──！”` | 字符/语音标记（角色或特效索引） |
| `#RRGGBBAA;` | `#000033ff;` | 文字着色 |
| `#;` | `……#;也要` | 颜色复位 |
| `\n`（字面反斜杠+n） | `——是啊。\n嘴唇…` | 强制换行 |
| `\k` / `\p` | `…\k%123;不是…` | 点击等待类标记 |
| `\\` | `anim\\bg\\img_october` | 转义反斜杠（仅开发备注脚本里出现） |

匹配/翻译时把它们当**不参与翻译的记号**：数量与位置必须守恒。

## 6. 回写不变量（本作待阶段 4 实测；下面条款的机制来自 FHD 项目已验证的实现）

1. `length` = 目标版口径（§3），每条重算
2. 行内标记数量与相对顺序不变（§5）
3. 目标版是 3 元分页时只写 `text`；沿用 5 元分页才需要自己补 `text_plain`
   （本作：民汉 9,576 页是 5 元，Steam 只有 51 页有 `plain` ⇒ **只写 `text` + `length`**）
4. **不需要完整对象图序列化器**：文本是字符串池里的槽，`length` 与文本引用都是页面数组里的**定宽内联字段**，两者都能**原位改字节**（同字节宽度 ⇒ 后续偏移不动）。只有「一个字符串槽被多个页面共用、且这些页面要写不同译文」时才需要**追加**新槽（`rebuild(extra_strings=...)`，新槽号 = 池尾），并把该页的引用原位改指向新槽（新槽号必须仍落在旧引用的字节宽度内，否则只能保留多数票文本）
5. 同理，**内联整数的类型字节必须按族写回**：整数 `0x04+width`、字符串引用 `0x14+width`（写成整数类型会让解析器把文本当数字，页文本变成空串——实测踩过）
6. 改写后回读校验：`length == page_length(text)`、正文与预期一致、标记数一致、`voice` 未变、行数/页数未变
   （实现见 FHD 项目的 `script/writeback.py verify`，阶段 4 迁入本仓库后改用本作 102 脚本 / 23,245 页的取值）

### 6.1 已知的不可分离结构：共享页列表对象

官方脚本会把**完全相同的页列表去重成同一个对象**（PSB 图是 DAG，不是树），于是两个不同 `row`可能共用同一个页数组——连 `length` 槽都共用。这类行**只能写同一段文本**，除非做对象图手术（新增页列表 + 改父数组计数 ⇒ 需要完整序列化器）。

本作实测（FHD 项目的数据仅供对照）：FHD 的 52,133 页里有 13 页受此限制；本作的页数、共享页数量需要在阶段 4 的
`verify` 环节重新统计并记入 `tmp/_report_apply.json`。结构同构（`script/align_check.py`）只保证行数/页数一致，
不保证共享槽分布一致。

### 6.2.1 耗时构成（为什么这一步慢）

下面数字来自 FHD 项目（同一份 `tool/psb.py`、同一台机器）：单个 3 MB 的脚本实测：解析 PSB 图 2.2 s、
按路径记录槽位 2.4 s、重建字符串池 0.05 s、mdf 外壳 zlib(9) 2.3 s。即**纯 Python 的对象图遍历**与**压缩**是两头开销；
`fetch` 另需把 1–2 GB 的加密归档做一次映射表解析（本作 `Hxv4Archive` 用 `mmap`，只在访问条目时分页）。
因此 `apply` 按脚本并行（`--jobs`），`verify` 串行。本作的实测耗时待阶段 4 补充。

### 6.3 匹配/回写口径：位置映射

- **一律按位置映射**（`chs (script, scene, row, page) → steam 同键`），不做交叉映射、不需要模糊对齐。
- 本作两版**结构零差异**（`script/align_check.py`：行数、`(scene,row)` 键序列、页数、voice id、`char_id`、
  speaker 有无、选项 index 全等）⇒ 与 FHD 不同，**没有任何“内容对调”或“改写压缩”的例外**。
- 依据：民汉补丁是对日文原版 PSB 的**原位字符串替换**（结构、行数、voice 槽全部继承原版），其语序即原版语序。
- 影响面：带语音的 10,964 行 voice id 逐一相同，位置写入不会造成语音不同步。

### 6.2 回写流水线（`script/writeback.py`）

| 子命令 | 作用 |
|---|---|
| `fetch` | 从 3 个加密归档解出**简中域**脚本到 `tmp/zhcn_psb/`（带 `file_hash` 清单） |
| `roundtrip` | 闸 1：零改动重建 body 逐字节相同；闸 2：单条字符串变长/变短后仍能解析且池内容一致；闸 3：每页 `length` 内联槽位置与提取结果逐页一致 |
| `apply` | 位置映射写入文本 + 选项文本 + 重算 `length` + 共享槽分流，产出 `tmp/out_zhcn/` 与 `tmp/_report_apply.json`；`--jobs`（默认 8）按脚本并行 |
| `pack` | 打成明文 xp3（条目名 `<script>.scn`，索引 zlib） |
| `verify` | 读回包：条目名哈希、文本、标记、`length`、`voice`、结构逐页校验 |

## 7. 场景结构与版本的对应关系（本作实测）

两版共有 **102 个脚本 / 117 段场景 / 23,245 条对白**，Steam 的每一条对白可按
`(脚本, 场景 label, 行号, 页号)` **100% 一一对应**；同一位置的两条文本是同一句原文的不同译本。

民汉多出的 16 个脚本（`airi_route*` 4 / `ange_route*` 11 / `sakuno_route01_10` 1，共 5,009 行）属于本作没有的其它女主角路线，
移植时直接跳过；Steam 侧**没有**民汉缺的脚本。

逐条核对过的对齐统计（`script/align_check.py`）：

| 项 | 结果 |
|---|---|
| 场景数 | 民汉 134 / Steam 117（差 17 段全在那 16 个不可移植脚本里） |
| 对白行 | 23,245，**逐脚本行数差异 0** |
| 每行页数 | 23,245 行全等 |
| 旁白 / 对白性质（`speaker` 是否为空） | 23,245 / 23,245 一致 |
| 语音 id（`pages[].voice`） | 两侧都有语音的行 **10,964**，**id 100% 相同**；两侧都无语音 12,281 行 |
| `char_id` | 23,245 页全等 |
| 逐页说话人（`alt_speaker`） | 民汉 242 页有值，Steam 15,297 页有值；**没有「民汉有、Steam 无」的情况** ⇒ 回写保持 Steam 原值不动 |
| 选项 `index` | 11 / 11 全等 |
| 民汉日文残留 | 共有脚本内 10 行（人名/拟声或漏译，需单独处理） |

⇒ 匹配与回写都以 `(脚本, 场景, 行号, 页号)` 为对齐键；**语音 id 相同的 10,964 行可直接判定为同一句**；
其余无语音的 12,281 行结构与行号已对齐，`resource/match/pairs/` 里标成 `needs_review`，含义是「待语义抽查」
而不是「待对齐」。

### 7.1 语言域之间的结构一致性（匹配结果可复用）

`cn/scn/`、`tw/scn/`、`en/scn/` 三域逐脚本对比结果：

| 项 | 结果 |
|---|---|
| 脚本数 | **各 102**（与 FHD 不同，本作没有“某域多几个脚本”的情况） |
| 对白行 / 页 | 23,245 / 23,245，一个不差 |
| 场景 label、`row`、页数、`char_id`、选项 `index` | **全部相同** |
| `voice` id | 10,964 条带语音页全部相同，零不一致 |
| 译文与字符串池下标 `text_idx` | 不同（简/繁/英三份译文，且各域字符串池排序不同） |

⇒ **结构严格一致，只有译文与字符串池位置不同**：任一域上得到的 `(script, scene, row, page)` 对齐结论可直接复用；
但**回写必须用目标域自己的 `text_idx` / `length`**（不能拿繁中的下标去写简中）。
本项目只保留简中产物；需要繁中/英文时同一条命令换 `--domain` 重提（约 30 秒）。
